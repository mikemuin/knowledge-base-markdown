# Clinical Workflow Categories: Detailed Task Classification System

## 1. Reviewing
Key Examples:
- Reading latest progress notes to understand overnight events
- Examining trending lab values (e.g., tracking creatinine over 5 days)
- Analyzing CT scan results with comparison to previous studies
- Checking medication administration records for pain control patterns
- Studying vital signs trends during post-operative recovery

Differentiator: Reviewing is passive information consumption, distinct from Evaluating which involves active assessment and judgment.

## 2. Ordering
Key Examples:
- Ordering stat CBC and basic metabolic panel for acute changes
- Prescribing antibiotics with specific administration timing
- Requesting urgent CT pulmonary angiogram for suspected PE
- Ordering hourly neuro checks for post-stroke monitoring
- Requesting physical therapy evaluation for mobility assessment

Differentiator: Ordering initiates actions but differs from Carrying Out which involves direct execution. Orders are requests for action by others.

## 3. Documenting
Key Examples:
- Writing detailed H&P for new admission
- Recording procedure notes with specific technical details
- Documenting informed consent discussions
- Writing discharge instructions with medication changes
- Creating nursing care plan with specific interventions

Differentiator: Documenting creates permanent records, unlike Communicating which involves real-time information exchange.

## 4. Acknowledging
Key Examples:
- Signing off on critical lab values (e.g., potassium 6.5)
- Confirming receipt of cardiac telemetry alerts
- Verifying completion of operative consent
- Accepting ED-to-floor patient handoff
- Confirming medication reconciliation review

Differentiator: Acknowledging closes communication loops, unlike Monitoring which involves ongoing observation.

## 5. Carrying Out
Key Examples:
- Performing bedside procedures (e.g., central line placement)
- Administering IV medications
- Conducting thorough physical examination
- Performing wound dressing changes
- Executing CODE BLUE protocols

Differentiator: Carrying Out involves direct action, unlike Coordinating which manages others' actions.

## 6. Monitoring
Key Examples:
- Continuous tracking of ventilator parameters
- Hourly neurological assessments post-TPA
- Following urine output in acute kidney injury
- Tracking pain levels after medication administration
- Monitoring post-operative bleeding

Differentiator: Monitoring is active surveillance, different from Reviewing which examines historical data.

## 7. Planning
Key Examples:
- Creating weaning protocol for ventilator support
- Developing antibiotic step-down plan
- Establishing goals for diabetes management
- Designing post-stroke rehabilitation strategy
- Creating contingency plans for clinical deterioration

Differentiator: Planning sets future direction, unlike Ordering which initiates immediate actions.

## 8. Communicating
Key Examples:
- Conducting family meeting about goals of care
- Performing structured SBAR handoff
- Teaching patient about new insulin regimen
- Leading multidisciplinary rounds discussion
- Providing real-time updates during rapid response

Differentiator: Communicating involves active exchange, unlike Documenting which creates static records.

## 9. Coordinating
Key Examples:
- Managing complex discharge with home services
- Orchestrating multiple consultant recommendations
- Arranging transfer to higher level of care
- Coordinating operating room schedule changes
- Managing bed flow during capacity constraints

Differentiator: Coordinating organizes multiple activities/people, unlike Planning which creates action frameworks.

## 10. Evaluating
Key Examples:
- Assessing response to diuretic therapy
- Analyzing effectiveness of pain management plan
- Determining readiness for ventilator weaning
- Reviewing appropriateness of antibiotics
- Assessing whether patient meets discharge criteria

Differentiator: Evaluating involves clinical judgment and decision-making, unlike Reviewing which involves information gathering.

## Common Cross-Category Scenarios:

1. Managing Sepsis:
- Reviewing (check labs, vitals)
- Evaluating (assess severity)
- Ordering (antibiotics, fluids)
- Carrying Out (IV placement)
- Monitoring (track response)

2. Discharge Planning:
- Planning (create timeline)
- Coordinating (arrange services)
- Communicating (instruct patient)
- Documenting (write summary)
- Acknowledging (verify completion)
